Office users

These logins open the office share from office PCs (SMB3). It contains every machine's folder.

Connecting from Windows

Folder\\{{ share_host }}\CNC
User name{{ server_name }}\username, e.g. {{ server_name }}\{{ (site.office_users | first).name if site.office_users else 'programmer' }}
Passwordthe user's password from this page

Type the {{ server_name }}\ in front of the user name. Without it, a PC on a Windows domain sends its domain login (shown as DOMAIN\username) and the server refuses it. In Map network drive, tick Connect using different credentials, then More choices → Use a different account. Command prompt:
net use Z: \\{{ share_host }}\CNC /user:{{ server_name }}\username * /persistent:yes
