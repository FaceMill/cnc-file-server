How to connect: {{ machine_types[t].label }}

{% if t == 'haas-classic' %}

On the SETNG page, Network settings (around settings 900–916; check your machine's manual for the exact numbers):

  1. CNC Network Name: a short unique name, e.g. {{ m.name | upper }}
  2. Obtain Address Automatically: OFF; IP, subnet mask and gateway as above
  3. Domain/Workgroup {{ site.workgroup }}
  4. Remote Server Name {{ server_ip }}, Remote Share Path {{ m.name }}
  5. User Name and Password as above
  6. Power-cycle the control. The share appears as the network device in List Program.
{% elif t == 'haas-ngc' %}
  1. Press SETTING, then go to the Network tab. Under Wired Connection: DHCP Off; IP, subnet mask and gateway as above. Apply.
  2. On the Net Share tab: Remote Net Share Enabled On; Remote Server Name {{ server_ip }}; Remote Share Path {{ m.name }}; Remote User Name and Password as above; Domain {{ site.workgroup }}. Apply.
  3. In Device Manager (LIST PROGRAM), the Net Share tab shows the folder.
{% elif t == 'siemens-840d-pcu50' %}

On the PCU 50 (Windows XP and HMI Advanced). Windows access usually needs the service/OEM login.

  1. Exit to Windows. In Network Connections, open the company network adapter (usually Eth 1). Do not change the system network adapter (Eth 2, 192.168.214.x), which connects to the NCU and machine control panel.
  2. Set the IP and mask as above, with no gateway and no DNS.
  3. Map a network drive (e.g. N:) to \\{{ server_ip }}\{{ m.name }} with "Reconnect at logon", connecting as user {{ m.name }}.
  4. Make the drive available in HMI Advanced (Services area / logical drive setup in your HMI version) and restart the HMI.
{% elif t == 'siemens-operate' %}
  1. Commissioning area: Network → Company network (X130): IP and mask as above, no gateway.
  2. Commissioning → HMI → Logical drives: add a drive of type USB/network: Windows network, path //{{ server_ip }}/{{ m.name }}, user {{ m.name }} and the password above. Choose the access level and soft-key text you want.
  3. Save and restart HMI Operate. The drive appears in Program Manager.
{% elif t == 'heidenhain-tnc' %}
  1. Program Management → Net (enter the code number for network settings if asked). Set the X26 interface IP and mask as above, no gateway.
  2. Define a network connection: Mount device SMB (Windows share), server {{ server_ip }}, share {{ m.name }}, user {{ m.name }} plus the password, Workgroup {{ site.workgroup }}, Auto mount on.
  3. The drive appears in Program Management. Older iTNC 530 controls use SMB1, newer TNC 640/620 use SMB2/3; both work.
{% elif t == 'windows-cnc' %}
  1. Exit to Windows (usually needs the maintenance/OEM login). Set the network adapter that faces the shop network: IP and mask as above, no gateway. Don't change adapters that connect internal machine components.
  2. Map a network drive to \\{{ server_ip }}\{{ m.name }} with "Reconnect at logon", user {{ m.name }} and the password above.
  3. Select the mapped drive in the control's program/file manager (Mazak: Data I/O; Okuma: File manager; Hurco: Program Manager).
{% elif t in ('fanuc-dataserver', 'fanuc-embedded') %} {% set port_key = 'ETHBRD / Data Server board' if t == 'fanuc-dataserver' else 'EMBED (embedded Ethernet)' %}
  1. SYSTEM → [+] → [ETHPRM] (or [EMBED]/[ETHBRD]), interface {{ port_key }}, COMMON screen: IP address and subnet mask as above, router blank.
  2. FTP TRANSFER (host) screen, connection 1: Host name {{ server_ip }}, Port 21, User {{ m.name }}, Password as above, Login folder blank.
    3. {% if t == 'fanuc-dataserver' %}
  3. Data Server settings: set the data server mode to FTP mode, so the Data Server works directly on the Pi's folder.
  4. Parameter 20 (I/O channel) = 5 (Data Server) for input/output, or select the Data Server device in the program directory.
  5. For DNC operation of large programs, select the data server as the DNC device and run directly from the Pi's folder.
    6. {% else %}
  6. Parameter 20 (I/O channel) = 9 (embedded Ethernet).
  7. In EDIT mode, program directory → [DEVICE] → [EMBED] (host) lists the Pi's folder. Read and punch programs from there.
    8. {% endif %}
  8. Power-cycle if the control asks. Screen and parameter names vary by series (0i-D/F, 30i/31i/32i); check the FANUC Ethernet manual.
{% elif t == 'fanuc-focas' %}
  1. SYSTEM → [+] → [ETHPRM] (or [EMBED]), embedded Ethernet port, COMMON screen: IP address {{ m.ip }}, subnet mask {{ netmask }}, router blank.
  2. FOCAS2 screen: TCP port {{ m.focas.port }}. Leave UDP and the time interval at 0.
  3. Power-cycle the CNC if it asks. FOCAS2 over embedded Ethernet is standard on 0i-D/F and 30i/31i/32i. Older 16i/18i/21i need the Ethernet board or option.
  4. To write programs, turn the program-protect (memory protect) key off. Programs O8000–O9999 may also be protected by parameter 3202 (NE8/NE9).
  5. Writing or deleting the program the CNC is running is refused. Reset the CNC first.
{% elif t == 'ftp-other' %}
  1. Set the control's Ethernet IP and mask as above, with no gateway.
  2. In the control's host/FTP settings (e.g. Mitsubishi M70/M80 "Host" parameters, Brother "FTP" settings): host {{ server_ip }}, port 21, user {{ m.name }}, password as above, directory /.
  3. If the control asks for a host type or list format, choose UNIX (or Automatic).
{% elif t in ('fanuc-rs232', 'serial-other') %}
  1. Cable: a null modem. For XON/XOFF (Fanuc, Haas), wire TXD↔RXD and GND (adapter DB9 3→2, 2→3, 5→7 at a CNC DB25). Jumper RTS–CTS, and DTR–DSR–DCD, at both ends. Without the CNC-side jumpers, a Fanuc stops with alarm 086 (DR signal off). See docs/SERIAL-PORTS.md for RTS/CTS wiring.
    2. {% if t == 'fanuc-rs232' %}
  2. Fanuc (0i/16i/18i/21i/30i): parameter 0020 = I/O channel (0). For channel 0: 0101 bit 0 = 1 (2 stop bits), 0102 = 0 (RS-232 with DC1–DC4 codes), 0103 = baud (10 = 4800, 11 = 9600, 12 = 19200). ISO code, even parity, 7 data bits, XON/XOFF. Drip-feed runs in REMOTE (RMT/TAPE) mode.
    3. {% else %}
  3. Haas: settings 11 (baud), 12 (parity), 13 (stop bits), 14 (synchronization = XON/XOFF), 37 (data bits); 55 (Enable DNC from MDI) = ON. Punch the request from LIST PROG → Send RS-232. Enter DNC by pressing MDI/DNC twice, then Cycle Start. Other controls: set the RS-232 port to match the line settings above.
    4. {% endif %}
  4. Call a program from the machine: make a small program with the request comment and punch it out: 
    %
O9999 (SEND O1234)
M30
%
    SEND accepts an exact file name, a name without extension, or a program number. Within the send delay ({{ s.send_delay | round(1) }} s), switch the control to DNC/Remote/Tape mode and press Cycle Start. The Pi streams the file as the machine runs it.
  5. Save a program to the Pi: just punch it out. It lands in {{ m.name }}/received/ as O<number>_<date-time>.nc.
  6. Abort: reset the control and punch the call program again (the old send is dropped), or press Cancel send above.
{% endif %}

Keep file names short (8.3 style such as O01234.NC or PART1.MPF) for older controls.
